# 서울 대장아파트 퀴즈 🏠

> 서울 각 구의 대장아파트 사진을 보고, 지도에서 해당 구를 클릭하는 지식 테스트 게임

🎮 **[플레이하기 → playatgame.com/seoul-apt/](https://playatgame.com/seoul-apt/)**

---

## 게임 방법

1. 아파트 사진과 단지명을 확인한다
2. 서울 지도에서 해당 구를 클릭한다
3. 10~20문제 중 몇 개나 맞힐 수 있을까?

## 수록 단지

서울 25개 구의 대장아파트 54개 수록

| 지역 | 대표 단지 예시 |
|------|--------------|
| 강남구 | 도곡동 타워팰리스, 압구정동 현대아파트 |
| 서초구 | 반포동 아크로리버파크, 래미안퍼스티지 |
| 송파구 | 잠실동 엘스·리센츠·트리지움, 잠실주공5단지 |
| 용산구 | 한남동 나인원한남, 이촌동 래미안첼리투스 |
| … | 전 25개 구 수록 |
